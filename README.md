# Energy Level

Track what charges and drains your energy — together.

A couples' "energy battery" tracker: log what helped or hurt across a few
life domains (relationship, body, mind, life admin), watch a battery level
rise and fall over the day, and see the trend over time. Share a snapshot as
a picture or a live link.

Everything runs client-side — there's no backend or account. All data lives
in the browser's `localStorage`; a backup code lets you move it between
devices.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Built with Next.js (App Router), React, TypeScript, and Tailwind CSS.
